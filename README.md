# Recharge DS 3

Calcule chaque soir l'heure de recharge de la DS 3 Crossback E-Tense pour atteindre la batterie visée en heures creuses, et (phase 2) programme directement la prise Smart Life.

- `site/` : la page (calcul, paramètres, frise de la nuit, coût)
- `PLAN.md` : phases, points d'arrêt, critères d'acceptation
- `GUIDE-DEMARRAGE.md` : pas à pas pour lancer le projet avec Claude Code
- `CLAUDE.md` : contexte et règles pour les agents
- `SECURITE.md` : risques, mesures et procédures de révocation

Tests : `node --test tests/`
